# Holy Spirit Meditation (72) — Multilingual Final PWA

One responsive website/PWA with 24 integrated language versions:
English plus Chinese, Japanese, Korean, Hindi, Arabic, Turkish, Persian, Urdu,
Indonesian, Spanish, Portuguese, French, German, Italian, Russian, Ukrainian,
Polish, Swahili, Tagalog, Hebrew, Croatian, Latin, and Greek.

The language selector changes:
- interface
- keyword gate
- opening
- Creed
- Our Father / meditation text
- status text
- browser speech-synthesis narration
- right-to-left layout for Arabic, Persian, Urdu, and Hebrew

The 15 supplied preview screens are embedded directly in index.html, so the visual
pages do not depend on an external image folder.

Note: the original preview artwork is retained as the visual foundation. Therefore
English words physically baked into the original artwork remain visible; the
localized meditation content, controls, and narration are translated.

The current package contains the first-part 15-screen visual sequence, not 72 unique
visual screens.

For PWA installation, host over HTTPS (or localhost during development).
